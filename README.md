# 302Found | 시니어 금융교육 서비스 기획

5060 세대를 위한 금융교육 서비스의 사업화 검증과 MVP 개발 계획을 정리한 프로젝트입니다.

## 🧩 프로젝트 개요

5060 시니어 세대를 위한 맞춤형 금융 교육 플랫폼 개발.  
정보 부족으로 인해 노후자산 관리에 어려움을 겪는 시니어층을 대상으로,  
**직관적이고 실용적인 금융 콘텐츠**와 **모의투자·리워드 시스템**을 통해  
금융 이해도를 높이고, 자산 형성에 실질적인 도움을 주는 것이 목표입니다.

---

## 🎯 프로젝트 목표

- 5060 세대의 금융 지식 향상 및 투자 활성화
- 시니어층의 정보 격차로 인한 투자장애 해소
- 사용자 니즈 기반 검증(PMF) 및 자생 가능한 비즈니스 모델 구축
- 실질적인 노후 준비에 기여하는 서비스 제공

---

## 📚 프로젝트 주요 내용

### 1. 교육 콘텐츠 제작
- 시니어 눈높이에 맞춘 금융 입문 교육 콘텐츠 개발
- 예시 중심의 실용적 강의, 단계별 난이도 구성
- 영상 또는 슬라이드 기반 콘텐츠로 접근성 강화

### 2. 사용자 검증 및 피드백 수집
- 시니어 커뮤니티·복지관과 협업하여 초기 사용자 모집
- 시제품 테스트를 통한 사용자 반응 조사 및 피드백 수렴
- 리워드 제공으로 적극적인 참여 유도

### 3. 플랫폼 기능 기획
- 시니어 친화적 UI/UX 설계
- 주요 기능:  
  - 금융 정보 학습  
  - 모의투자 기능  
  - 리워드 프로그램  
  - 학습 이력 관리 시스템

### 4. 전문가 자문
- 지도교수와 2회 이상 자문 회의
- 플랫폼 실현 가능성, 사업화 전략, 마케팅 방향성 논의
- 필요 시 금융 전문가 및 UX 디자이너 추가 자문
