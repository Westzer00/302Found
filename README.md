# 302Found | 시니어 금융교육 서비스 기획

5060 세대를 위한 금융교육·모의투자 서비스의 초기 사업화 기획 기록.

## 문제와 목표

- 금융정보를 어렵게 느끼는 중장년층을 위한 쉬운 교육 콘텐츠
- 실제 투자 전에 기본 개념을 연습할 수 있는 모의투자 흐름
- 사용자의 학습 지속을 돕는 리워드·이력 관리 기능 검토

## 기획한 기능

| 영역 | 내용 |
|---|---|
| 교육 | 초보자용 금융 기초 콘텐츠와 단계별 학습 |
| 모의투자 | 가상 투자 경험 및 학습 피드백 |
| 사용자 경험 | 시니어 친화적 화면과 쉬운 탐색 |
| 검증 | 사용자 인터뷰·설문을 통한 이용 의향 확인 |

## 프로젝트 범위

사업화 방향과 MVP 기능을 정리한 **기획 프로젝트**. 서비스 구현·출시 결과가 담긴 저장소는 아님.

*Pandas 기초 실습 노트북은 이 프로젝트와 무관하여 Git 기록으로만 보관.*
